ACCEPTABILITY CRITERIA (defined by me)
  C1 latency    : one worst-case lookup <= 50 ms (feels instantaneous on a technician's screen)
  C2 utilisation: lookups (avg n/2 comparisons each) use <= 10% of one core, leaving headroom
  => C1 limit: n <= r*0.05 = 1121582 records
  => C2 limit: q * n / 2 <= 0.10 * r  ->  q * n <= 4.49e+06  (q = lookups per second)
